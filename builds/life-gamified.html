02 — The insight

The insight

The premise is simple: life should feel like an epic adventure. So the everyday list gets the grammar of a role-playing game. A task is a quest, finishing it earns XP, and the rewards in the treasure chests are real ones you choose.

03 — How it was built

How it was built

  • AI toolsBuilt with Claude Code.
  • AppReact 19 and Framer Motion, published on GitHub Pages. Every push to the main branch deploys through a GitHub Actions workflow.
  • Game engineOne file holds the game rules, and both the app and the server use it, so XP, streaks and rewards come out the same whoever records a deed. The engine has its own tests.
  • StorageLocal-first, with cloud sync to Supabase. If you and your agent write at the same moment, the app replays your taps on top of the agent's change, reusing the same dice rolls.
  • Agent accessA Supabase Edge Function gives AI assistants a REST API and an MCP endpoint, and also sends push notifications and runs a scheduled sweep.
  • SecurityRow Level Security limits every table to its owner. Agent keys are stored only as SHA-256 hashes.

04 — What it does

What it does

It is an illuminated, leather-bound RPG journal for your actual life. You post quests, earn XP and gold, level up, keep streaks, and win treasure chests that hold real rewards you choose.

  • Quest boardPost a quest in one line with shorthand, such as Run 5k #health !hard @tomorrow *daily, or open the full Quest Contract for descriptions, bonus objectives, quest chains and recurrence.
  • ChronicleA day-by-day journal of every deed, with the XP breakdown, notes from your agent, and undo.
  • CharacterFive classes, four attributes, HP and MP, levels, and three abilities. Talents come in five paths of three ranks, with a point every five levels.
  • RewardsTreasure chests in five tiers on a variable-ratio schedule, with cooldowns and seasonal rewards, plus bonuses for streaks, the first deed of the day, category combos and mastery.
  • Records20 trophies, a 20-week heatmap, streak history, a category compass rose, a difficulty breakdown and personal records.
  • AI scribeCreate an agent key in Settings and an AI assistant can log deeds for you over REST or MCP. Its writes show up in the app live, and its chests and level-ups play their ceremonies the next time you open the journal.
  • EverywhereInstalls to your phone's home screen, works offline and syncs when you're back online. Push notifications send a morning digest and a streak-guard nudge. Calm mode turns most of the animation down.
